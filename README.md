# KRAON - Premium Digital Marketing Agency Website

A modern, responsive single-page website for KRAON digital marketing agency, built with React, Vite, Tailwind CSS, and Express.js.

## Features

- **Responsive Design**: Fully responsive across all devices with dark, futuristic aesthetic
- **Smooth Animations**: Powered by Framer Motion with parallax effects and micro-interactions
- **Contact Form**: Working contact form with server-side validation and email notifications
- **Modern Stack**: React + Vite + Tailwind CSS + Express.js + Nodemailer
- **Glassmorphism Effects**: Premium UI with glass effects and gradient accents
- **SEO Optimized**: Proper meta tags and semantic HTML structure
